# Support

- **Documentation** — <https://twilight-project.github.io/twilight-core/> (concepts, module
  reference, and operator guides).
- **Bugs and feature requests** — open a
  [GitHub issue](https://github.com/twilight-project/twilight-core/issues/new/choose) using
  the templates provided.
- **Questions** — start with the documentation. If it does not answer your question, or is
  wrong, open an issue; a documentation gap is a valid bug report.
- **Security vulnerabilities** — do **not** open a public issue. Report privately through
  [GitHub Private Vulnerability Reporting](https://github.com/twilight-project/twilight-core/security/advisories/new);
  see [`SECURITY.md`](SECURITY.md).
- **Conduct concerns** — see [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

Twilight Core is a pre-1.0 project running as a public testnet whose tokens have no value;
support is best effort.
